# The Daily Edge V2 — Live Dashboard

Phone-first research dashboard for The Daily Edge V2.

Live site: https://wizwit1111.github.io/daily-edge-live/

## iPhone install
1. Open the live site in Safari.
2. Tap Share.
3. Tap **Add to Home Screen**.
4. Launch **Daily Edge** from the Home Screen.

The V2 interface is an installable PWA with an offline app shell, sport filters, Singles/Props, DFS, Combos, Results, and System views.

Research status is shown explicitly. Markets do not become official plays simply because they are visible in the dashboard; publication and automated wagering remain disabled unless separate validation/safety gates are deliberately changed.
